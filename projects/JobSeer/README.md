# JobSearch — AI-Powered Local Job Pipeline

A tool for local job search and automated fit scoring.

## Features
- Multi-source job ingestion (ATS, government, custom scrapers)
- Local SQLite job database
- AI fit scoring via Claude
- Interactive TUI for management

## Setup
```bash
uv sync
uv run playwright install chromium
```

## Usage
```bash
uv run jobsearch ui
```
