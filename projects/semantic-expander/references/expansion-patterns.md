# Expansion Patterns

Use these patterns to expand simple, "low-fidelity" requests into comprehensive plans.

## Finance & Taxes
- **Triggers**: "Taxes", "IRS", "Investing", "Banking"
- **Expansion Keys**: 
  - Forms (1099, W-2, 1040)
  - Deductions (Standard vs Itemized)
  - Deadlines (Filing dates, extension dates)
  - Regional variations (State vs Federal)
  - Recent policy changes

## Software Development
- **Triggers**: "Fix this bug", "Implement feature", "Refactor"
- **Expansion Keys**:
  - Reproduction (Step-by-step, test cases)
  - Analysis (Stack traces, logs, related symbols)
  - Implementation (Edge cases, type safety, performance)
  - Validation (Unit tests, integration tests, linting)
  - Documentation (Docstrings, README updates)

## Content Creation
- **Triggers**: "Write a post", "Create a video", "Draft a newsletter"
- **Expansion Keys**:
  - Research (Current trends, competitor analysis)
  - Structure (Outline, hook, key takeaways, call-to-action)
  - SEO (Keywords, meta descriptions, alt text)
  - Distribution (Social media snippets, email subject lines)

## Research & Learning
- **Triggers**: "Search for...", "Learn about...", "Explain..."
- **Expansion Keys**:
  - Foundational concepts
  - Key terminology/Glossary
  - Historical context or evolution
  - Expert opinions or leading sources
  - Practical applications or tutorials
